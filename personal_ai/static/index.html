Requires your Minecraft server

Minecraft Java bridge

A standalone Mineflayer controller provides observations and bounded movement, digging, and crafting actions. Connect only to a server you own or have permission to automate.

Run node adapters/minecraft/bridge.cjs --authorized from a local terminal. Controls and limitations are documented in the README.

Not connected to this dashboard. No live observations or success rates are available. Combat, navigation learning, and visual window control are not implemented.

Control boundaries

The web application cannot send desktop input, start programs, or control Minecraft. The standalone bridge has separate pause and stop commands. Workbench emergency stop does not stop that separate process.
